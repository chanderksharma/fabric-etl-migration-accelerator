# Support

## Getting Help

- **Documentation**: Start with [`README.md`](README.md), [`docs/Guides/getting-started.md`](docs/Guides/getting-started.md), [`docs/Guides/fabric-ci-cd-setup.md`](docs/Guides/fabric-ci-cd-setup.md), and [`docs/Guides/troubleshooting.md`](docs/Guides/troubleshooting.md).
- **Defects & Feature Requests**: Open an issue in this GitHub repository with reproduction steps using synthetic workflow fixtures only (never attach customer workflows or data).
- **Chrysalis Asset Feedback**: Submit reuse feedback, realized value, or questions directly on the asset's **Chrysalis** details page (`https://portal.chrysalis.ms`).
